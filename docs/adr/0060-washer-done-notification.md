# ADR-0060: Сповіщення про завершення прання — через вебхук за потужністю розетки

- **Status**: accepted
- **Date**: 2026-09-29

## Контекст

Користувач попросив (особиста нотатка через Велешу): коли пральна машина
завершує цикл, надсилати сповіщення. Пралка не «розумна» — вона на
розумній розетці (`switch.pralka`), тож окремого стану «прання
завершено» немає; є лише `sensor.pralka_zhyvlennya` (Вт).

Історія 19–29.09.2026 (14 циклів):
- простій ≈3 Вт, прання 20–1800 Вт;
- посеред циклу потужність регулярно падає до 3 Вт — найдовший такий
  провал ≈200 с;
- між сусідніми циклами — щонайменше 18 хв;
- найкоротший справжній цикл — 34 хв; трапляються секундні сплески
  (поворот ручки програм, 32 Вт) без циклу.

## Рішення

Та сама схема, що й ADR-0057: HA сигналізує, наш сервер шле в Telegram.
Код Велеші не змінюється — `/webhook/{name}` уже універсальний.

Автоматизація в HA (`docs/ha/washer-done-automation.yaml`, створена
через `POST /api/config/automation/config/velesha_washer_done`):
тригер — потужність > 20 Вт; далі `wait_for_trigger` потужність < 5 Вт
протягом 5 хв (запас ×1.5 до найдовшого провалу посеред циклу); умова —
від старту минуло > 15 хв (відсікає сплески від ручки); дія —
`rest_command.velesha_webhook` з `name: washer-done`.

Замість окремої `rest_command` на кожну подію (як у прикладі ADR-0057) —
одна узагальнена, `name` і `message` передаються з автоматизації. Її
треба додати в `configuration.yaml` вручну (REST/WebSocket API не пише
YAML-конфіг):

```yaml
rest_command:
  velesha_webhook:
    url: !secret velesha_webhook_url
    method: POST
    content_type: "application/json"
    payload: '{"message": {{ message | tojson }}}'
```

`secrets.yaml`:
```yaml
velesha_webhook_url: "http://192.168.88.13:8090/webhook/{{ name }}?token=<WEBHOOK_TOKEN>"
```

## Наслідки

- Автоматизація в режимі `single` + `max_exceeded: silent`: протягом
  циклу потужність постійно перетинає 20 Вт, повторні тригери мовчки
  ігноруються.
- Якщо HA перезапуститься посеред прання, `wait_for_trigger` губиться —
  сповіщення за цей цикл не прийде. Прийнятно.
- Якщо розетку вимкнуть (`switch.pralka` off) посеред циклу, потужність
  стане 0 → «завершено» прийде через 5 хв. Прийнятно: це свідома дія
  користувача.
- Пилосос (ADR-0057) може перейти на ту саму `rest_command.velesha_webhook`.
