# ADR-0079: Фільм за посиланням (або назвою) → Толока; команда `/t`

- **Status**: accepted
- **Date**: 2026-10-07

## Контекст

Користувач дає Велеші посилання на Вікіпедію чи інший сайт про фільм, або
просто назву, і хоче знайти його на Толоці. Роздачі на Толоці названі
«Українська назва / Original (рік)», тож треба знати обидві.

## Рішення

- `tmdb.from_url`: IMDb (`/title/tt…` → `/find`), TMDB (`/movie|tv/<id>`),
  Вікіпедія будь-якою мовою → Wikidata (P4947 фільм, P4983 серіал, P345
  IMDb; хибний id → наступний; немає id → назва статті без «(фільм)»),
  інший сайт → `og:title` / `<title>` → `identify`.
- `film_find(query)` (адмінський, як Толока; відповідь дослівно, як
  `toloka_search`): визначає фільм, шукає на Толоці українською назвою,
  потім оригінальною, потім «оригінальна рік»; список той самий, тож
  «додай 2 у фільми» працює. Без визначення — звичайний пошук за назвою.
- Telegram: `/t <посилання або назва>` в особистих і в сімейній групі
  (в меню команд).
- Безпека: помилки TMDB — `TmdbError` без URL (там `api_key`/`session_id`);
  `telemetry._redact_url` вирізає `api_key`, `session_id`, `token` з URL у
  спанах (раніше — лише токен бота). Ключ TMDB один раз потрапив у вивід
  розробки — рекомендовано перевипустити.
