# ADR-0083: Вебсокет HA зсередини циклу подій; лише релевантні роздачі у film_find

- **Status**: accepted
- **Date**: 2026-10-08

## Контекст

- `vacuum alias fetch error: asyncio.run() cannot be called from a running
  event loop`: `ha_client._ws_command` робив `asyncio.run`, а псевдоніми
  пилососа (ADR-0073) читаються під час побудови промпту — всередині циклу
  подій ADK. Псевдоніми мовчки зникли, «Бичок» знову не впізнавався.
- `film_find` для «The Fix» (2026, ще не на Толоці): українською — нічого,
  за оригінальною короткою назвою — сторонні роздачі («The Holiday Fix
  Up»), подані як знайдене.

## Рішення

- `_ws_command`: якщо цикл уже працює — виклик на окремому потоці з
  власним `asyncio.run` (таймаут 30 с).
- `film_find` бере лише роздачі, в назві яких є українська або оригінальна
  назва фільму цілим словосполученням і рік (±1, або року в назві немає);
  пошук «назва рік» прибрано. Нічого релевантного → «На Толоці його ще
  немає». Список-нумерація винесено в `_toloka_list` (спільний з
  `toloka_search`), тож «додай N» працює як раніше.
