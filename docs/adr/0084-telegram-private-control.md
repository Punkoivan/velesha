# ADR-0084: Особисті повідомлення боту — з керуванням

- **Status**: accepted (замінює read-only з ADR-0070 для приватних чатів)
- **Date**: 2026-10-08

## Контекст

Користувач у особистих написав «додай 1 у фільми» після пошуку на Толоці —
Велеша відмовила (read-only, ADR-0070). Керування вже дозволене в сімейній
групі (ADR-0077); користувач хоче те саме в особистих.

## Рішення

Приватний чат з людиною з `TELEGRAM_ALLOWED_USERS`: без read-only, пристрій
`telegram-private` додано до `VELESHA_ADMIN_DEVICES` (права як у групі й
s21), пам'ять — особиста цієї людини; переслане не вчить пам'ять
(ADR-0071). Наслідок: «запам'ятай…» у особистих тепер працює (раніше було
вимкнене разом із керуванням). Read-only режим лишається в коді для
каналів, яким керування не дано.
