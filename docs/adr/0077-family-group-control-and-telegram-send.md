# ADR-0077: Сімейна група Telegram з керуванням; «скинь у Telegram» з HA

- **Status**: accepted
- **Date**: 2026-10-07

## Контекст

Користувач додав бота в спільну групу з дружиною. Хоче: керувати домом
звідти з правами як у s21-voice (ADR-0072), лише вони двоє; і щоб
Велеша з HA могла надіслати свою відповідь у Telegram — в особисті чи в
групу, а якщо з контексту не ясно куди, перепитати.

## Рішення

- `TELEGRAM_FAMILY_CHATS` — ID груп, де дозволено керування. Бот
  відповідає в групі лише людям з `TELEGRAM_ALLOWED_USERS`; режим
  приватності бота лишається ввімкненим (бачить лише звертання
  `@velesha_ha_bot`, відповіді на свої повідомлення, команди — не всю
  переписку). Звертання вирізається з тексту, відповідь — «відповіддю»
  на повідомлення.
- Повідомлення з групи: особа `shared`, пристрій `telegram-group`
  (адмін через `VELESHA_ADMIN_DEVICES`, як s21), без read-only, окрема
  сесія `tg-group-<id>`, пам'ять спільна. Особисті повідомлення боту —
  як і раніше лише читання (ADR-0070).
- `telegram_send(to, text)`: `me` — у особисті тому, хто говорить (людина
  → Telegram ID з `TELEGRAM_ALLOWED_USERS`), `group` — у сімейну групу, або
  ім'я людини з `VELESHA_NAMES` (з відмінками). Зі спільного пристрою
  «мені» невідомо кому — інструмент відмовляє, модель перепитує.
  Пропонується за словами «телеграм / в групу / в особисті / скинь /
  перешли / надішли / відправ»; серед CONTROL_TOOLS.
- У журнал бота для проігнорованих повідомлень — ID чату, назва, ID й ім'я
  відправника (щоб додати до білого списку).
