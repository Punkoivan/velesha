# ADR-0064: Рецепти в Grocy — чистий HTML у «Приготуванні», повні панелі інгредієнтів

- **Status**: accepted
- **Date**: 2026-10-03

## Контекст

Після перенесення Obsidian → Tandoor → Grocy поле «Приготування»
(`description`) містило сирий markdown Obsidian (`#`, `**`, таблиці),
службові рядки («Теги:», «Порцій:», «Крок 1: Рецепт», дубль назви) і
повний розділ «Інгредієнти». Панелі інгредієнтів (`recipes_pos`) при
цьому були неповні (194 з 232 позицій) і подекуди хибні: імпорт
(`_build_draft`) пропускав рядки без кількості («за смаком»), з
несумісною одиницею («2 ст.л.» для товару в грамах), діапазони — і
вигадував кількості («1 ч.л. цукру» → «Цукор 1 кг», «2 ст.л. олії» →
«2 л»), а зіставлення товарів помилялось («картопля» → «Крохмаль
картопляний»).

## Рішення

Разова переробка всіх 39 рецептів (скрипти поза репозиторієм, резервна
копія — JSON усіх рецептів і позицій до змін):

- `description` → HTML: кроки `<h4>` (або `<ol>`), розділи «Подача»,
  «Нотатки», «Калорійність» — `<h3>`, списки/жирне/цитати/таблиці —
  відповідні теги; службові рядки й інгредієнти прибрано.
- Панелі перебудовано вручну з тексту рецепта. `variable_amount` — текст
  як у рецепті («400–500 г», «2 ст.л.», «за смаком»), `amount` — в
  одиниці товару для розрахунку наявності. Три режими:
  - звичайний — кількість рахується;
  - «наявність» (`only_check_single_unit_in_stock`, amount 0) — спеції,
    сіль, дріжджі в ложках: лише «чи є взагалі»;
  - «необов'язково» (`not_check_stock_fulfillment`, amount 0) — вода,
    «за бажанням», «для подачі».
- Групи інгредієнтів (`ingredient_group`) там, де рецепт їх має
  (Маринад/Паніровка, Тісто/Крем тощо).
- «Банановий хліб» мав два методи з різними інгредієнтами — Bake/Roast
  винесено в окремий рецепт.
- Створено 16 товарів (без запасу), «сушений орегано» злито з «орегано
  сухий».
- `recipe_cook` (`_split_steps`) розбирає HTML: кроки — `<h4>` або `<li>`
  з `<ol>`, `<h3>`-розділи — додаткові кроки, калорійність і таблиці
  пропускаються, текст очищується для озвучення. Старий текстовий формат
  («1. …», «Крок N:») теж підтримується.

## Наслідки

- Спеції й сіль у Grocy без запасу — рецепти показують їх як нестачу,
  поки запас не заведуть.
- `recipe_add` / `_build_draft` досі пишуть по-старому (текст «1. …»,
  ті самі пропуски інгредієнтів) — виправлення окремо.
- Індекс пошуку (ADR-0063) переембедить усі рецепти на наступній
  синхронізації — опис змінився.
