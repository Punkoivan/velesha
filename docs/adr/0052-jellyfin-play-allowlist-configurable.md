# ADR-0052: Дозволені пристрої для відтворення Jellyfin — налаштовувані

- **Status**: accepted
- **Date**: 2026-09-26

## Контекст

«Перенеси серіал на ноутбук» не спрацювало — код мав жорстко закодований
allowlist з одним значенням, `KODI = "kodi"` (ADR-0021/0038), і будь-яка
інша сесія (напр. ноутбук через Jellyfin Web у Firefox) відхилялась
безумовно.

## Рішення

`_jellyfin_guard` (`api/adk_agent.py`) тепер звіряє сесію проти
`JELLYFIN_PLAY_ALLOW` — списку підрядків, розділених комою (env var, за
замовчуванням лише `kodi`), той самий патерн, що вже є в
`HA_CONTROL_ALLOW` (ADR-0039). На `acer` встановлено
`JELLYFIN_PLAY_ALLOW=kodi,firefox` — сесія `Firefox`/`Jellyfin Web`
(браузер ноутбука) тепер теж дозволена ціль.

## Наслідки

- Позиція відтворення НЕ переноситься — новий пристрій почне з
  Jellyfin-івського «наступна непереглянута серія», а не з точної миті,
  де зупинився Kodi. Справжній перенос позиції (читання
  `PositionTicks` вихідної сесії й передача в команду play) —
  окрема, ще не зроблена робота.
- `firefox` — заголовок клієнта, не прив'язаний до конкретного
  ноутбука; якщо колись інший пристрій теж відкриє Jellyfin Web у
  Firefox, він так само підпаде під allowlist. Прийнятно для
  домашнього використання одним-двома пристроями.
